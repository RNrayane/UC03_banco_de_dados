•	1. Banco de Dados Relacional: Modelo que organiza dados em tabelas (linhas e colunas) conectadas por chaves.

•	1.2. Problemas que resolve: Evita duplicação de dados, previne inconsistências e garante a segurança em alterações concorrentes (propriedades ACID).

•	1.3. SGBD: Sistema Gerenciador de Banco de Dados, o software que administra e controla o acesso aos dados.

•	1.4. Principais SGBDs: PostgreSQL, MySQL, SQL Server, Oracle e SQLite.

•	1.5. SQL: Linguagem padrão usada para consultar, inserir e gerenciar dados em bancos relacionais.

•	1.6. Aplicações do SQL: Sistemas financeiros, e-commerces, ERPs, CRMs e qualquer aplicação que exija alta consistência.

•	1.7. NoSQL: Bancos não relacionais para lidar com grande volume, flexibilidade de esquema e dados não estruturados.

•	1.8. Onde o NoSQL é usado: Redes sociais, sistemas de recomendação (streaming), IoT, chats e plataformas de Big Data.
